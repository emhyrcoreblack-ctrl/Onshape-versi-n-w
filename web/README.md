# Vista web de prueba — Modelo 3D Studio

Esta carpeta contiene el entorno web experimental para revisar la interfaz y probar el flujo CAD desde el navegador. La aplicación Android nativa permanece en `android/` y es el proyecto principal.

## Publicación
El workflow `.github/workflows/web-preview.yml` publica esta carpeta en GitHub Pages cuando cambia `web/**`.

La vista web es una implementación de prueba paralela: todavía no comparte el motor geométrico Kotlin ni sustituye la app Android.

# Modelo3D Studio v0.4

CAD 3D parametrico personal para Android (Boceto -> Extrusion -> Piezas -> STL).

## Como obtener el APK desde el celular
1. En el repositorio solo hacen falta DOS cosas: el zip del proyecto y `.github/workflows/build.yml`.
2. Cada vez que subas un zip nuevo, el workflow usa AUTOMATICAMENTE el mas reciente (no importa el nombre).
3. Actions arranca solo. Al terminar, abre la pestana **Releases** del repositorio y descarga `Modelo3DStudio.apk`.
4. Las versiones nuevas se instalan ENCIMA de la anterior (misma firma) y conservan tus proyectos.
